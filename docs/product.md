# 产品需求

## 定位

Codex Go 是个人使用的移动开发客户端和连接服务。用户使用自己的模型服务，在手机上管理开发任务，并在手机、电脑之间接续工作。

核心需求来自使用 API Key 和中转服务的场景，不把 ChatGPT 账号登录作为产品的必要前提。

## 核心场景

### 手机上开始开发

用户填写模型服务地址、API Key 和模型，选择一个可用运行环境，创建项目或克隆仓库，再新建对话开始开发。运行环境包括待验证的手机本地环境、个人电脑和用户自己的常驻主机。

参考 dsh-Go，手机本地运行是需要认真验证的产品方向。手机本地执行代码与模型在手机本地推理是两件事：前者使用手机的文件和工具，后者不在当前范围内；模型请求仍发送到用户配置的 API 服务。

### 离开电脑后继续已有工作

用户在手机上连接已经配对的电脑，选择项目与已有 Codex 对话，查看历史、当前任务和改动，再继续发送指令。若任务正在运行，先显示其状态，并通过受支持的接口接入；不可接入时说明原因。

### 手机上审阅和确认

用户能查看任务输出和文件差异，接受执行审批、拒绝请求、停止任务或补充指令。断网重连后能辨认任务是否仍在运行，避免把一次指令重复提交。

### 个人电脑不在线

手机本地运行验证通过后，用户可直接在手机的开发环境中新建项目和对话；也可以选择自己的常驻主机。项目所在主机、会话所在主机必须明确显示；在不同主机之间迁移项目、未提交改动和会话属于额外能力，不等同于切换设备。

## 需求清单

| 编号 | 需求 | 可观察的验收结果 |
| --- | --- | --- |
| R1 | 自定义模型服务 | 可配置地址、密钥和模型；连接失败时能区分鉴权、协议及网络问题，错误不泄露密钥。 |
| R2 | 手机可用界面 | 在首版支持的手机端完成项目选择、历史阅读、发消息、查看输出和审批；原生与网页验证结果分别记录。 |
| R3 | 连接自己的电脑 | 配对后能连接；撤销设备后，该设备不能再访问主机。 |
| R4 | 项目列表 | 显示用户明确授权的工作目录，正确区分不同主机的项目。 |
| R5 | 继续已有对话 | 在已验证兼容的会话中发送新消息后，继续使用原会话 ID、历史和工作目录。 |
| R6 | 新建项目 | 在授权的父目录内创建空项目或克隆仓库，返回明确结果并可开始对话。 |
| R7 | 新建对话 | 可在指定项目中创建会话，并显示其模型服务与运行主机。 |
| R8 | 实时任务操作 | 显示流式输出、执行状态、审批与改动；支持停止以及接口允许的补充指令。 |
| R9 | 断线恢复 | 恢复连接后核对任务状态、补载可获取的历史；重复提交不会悄悄启动第二个相同任务。 |
| R10 | 跨端接续 | 完成电脑 → 手机 → 电脑的同一会话往返验证，记录支持的版本与限制。 |
| R11 | 常驻运行环境 | 个人电脑离线时，仍可在用户自己的常驻主机上创建项目和运行任务。 |
| R12 | 手机本地运行 | Android 原型在没有电脑与其他开发主机的情况下，使用自定义 API 完成文件修改、工具执行和会话恢复；记录设备、运行时及权限限制。 |

## “无缝”的具体含义

- 保留原会话身份与已有上下文，不靠复制聊天文本冒充接续。
- 保留项目目录、所用模型服务和必要的执行配置。
- 能区分历史内容、当前执行状态与待处理审批。
- 在手机与电脑同时打开时，明确谁负责执行当前任务，避免重复执行或并发修改冲突。
- 客户端断线后，运行环境中的任务有明确的持续执行、停止或恢复行为。

桌面 App 中的项目分组、固定状态等界面信息，是否有受支持的访问接口尚未确定。会话接续成功不自动代表这些信息也已同步。

## 首个可交付闭环

建议先验证两个最小闭环，再决定首版范围：

1. **远程闭环**：一部手机、一台电脑、一个经验证的中转服务；配对 → 选择授权项目 → 新建或恢复已验证的会话 → 发起开发任务 → 查看输出和审批 → 电脑继续该会话。
2. **本地闭环**：Android 手机安装运行环境 → 配置 API → 创建本地项目与对话 → 执行一次文件修改 → 重启客户端并恢复会话。

常驻主机模式补充个人电脑离线的场景。若手机本地运行暂时不可行，应明确记录限制，再决定交付顺序。

## 初期范围之外

- 多人协作、组织管理、计费平台和公开托管服务。
- 首版同时实现 iOS 与 Android 原生客户端。
- 未经验证就承诺所有中转服务、所有桌面版本和所有历史会话均兼容。
- 自动同步不同主机的整个文件系统或迁移正在运行的进程。

## 隐私与控制

模型密钥由实际调用模型的运行环境保管，优先使用系统凭据存储；移动端保存连接凭据时使用平台安全存储能力。浏览器能力不足时优先使用有明确过期时间的会话，不默认长期保存明文模型密钥。

电脑连接凭据与模型 API Key 分开。远程执行遵守明确配置的授权目录与审批策略；手机端能看到等待自己处理的审批。日志默认隐藏密钥和连接令牌。
