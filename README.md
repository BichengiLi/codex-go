# Codex Go

面向个人使用的移动开发入口：在手机上使用自己的 API Key 和中转服务开发，并连接电脑上的 Codex，继续已有项目与对话，或创建新的项目与对话。

本项目为私人项目，与 OpenAI 官方无隶属关系。

## 为什么做

希望使用自己 API 服务的用户，需要一个适合手机的开发入口。电脑上的 Codex 使用 API Key 时，也需要方便的跨设备连接方式：离开电脑后，仍能查看任务进展、继续讨论、审阅改动并发起下一步工作。

Codex Go 希望把模型服务、开发运行环境和手机界面连接起来。

## 产品目标

- **自带 API**：配置服务地址、API Key 和模型，使用兼容的中转服务。
- **手机开发**：在手机上操作项目、发起任务、查看输出、审阅改动和处理执行审批。
- **连接电脑**：配对自己的电脑，访问授权的工作目录与 Codex 会话。
- **接续上下文**：进入已有对话时保留项目路径、历史上下文和任务状态。
- **随时新建**：直接创建新对话、创建空项目或克隆仓库。
- **不依赖个人电脑在线**：探索手机本地运行，并支持连接用户自己的常驻开发主机。

## 当前状态

**0.2.0 提供 Windows App 和 Android APK，新增渐入首页、扫码配对、独立后台连接和本地 API 模型选择。** 日常流程见[双端 App 使用指南](docs/native-apps.md)。命令行/网页入口继续用于开发与协议验证。

支持短时配对、设备撤销、导入 Codex App 已有项目、创建空项目、新建/接续会话、历史分页、流式输出、生成文件下载、命令/文件审批、会话权限调整、任务停止和断线状态恢复。任务提交使用持久化请求标识，结果未知时不会自动重跑。模型配置复用主机 Codex，或使用主机环境变量指定 Responses 服务。

已在真实自定义服务上完成文件修改、多轮上下文、App Server 重启后同一会话恢复；也已读取桌面 App 原有会话。Windows 内置主机已真实调用模型，Cloudflare 临时公网 HTTPS 地址已完成配对、鉴权读取及真实模型事件轮询。Android APK 已构建并通过 lint，设备上的本地执行和远程使用仍待真机验证。详见[验证记录](docs/validation-2026-10-31.md)及[App 验证范围](docs/native-apps.md#验证范围)。

## 快速启动

需要 Node.js 22.12+ 和 Codex CLI。本次固定验证版本：`0.166.0-alpha.5.1`。

```powershell
npm ci
npm run build
npm start -- --workspace "D:\Projects"
```

打开终端打印的本机地址，输入 8 位配对码。`--workspace` 是明确授权的根目录，可重复指定。默认复用电脑当前 Codex 配置，密钥不发送到浏览器。手机远程访问需配置 HTTPS 私有网络/代理；[运行说明](docs/running.md)包含连接方式、自定义 API、开发和 Android 探针。

- **选择已有项目**：侧栏“Codex App 项目”读取桌面保存的名称和目录，点选后载入该项目的对话。
- **获取文件**：点击回复中的下载链接、文件改动下的下载卡片，或“项目文件”浏览目录。支持 PDF、DOCX、ZIP 等普通文件，单文件上限 200 MB。
- **调整权限**：接续空闲对话后，点击“项目内读写 · 严格审批”等权限按钮，选择只读、项目内读写或完全访问，以及批准策略。界面显示主机确认的有效设置，重启后保留选择。

```powershell
npm test
npm run probe
# 显式使用当前服务调用模型，验证文件修改及恢复：
npm run probe -- --run --output .local/probe.json
```

## 初步方向

参考启发本项目的 [dsh-Go](https://github.com/ccch1mneyyy/dsh-Go)，采用“手机本地 + 远程主机”的产品方向，让同一套项目与会话界面适配不同运行环境。

Windows 的独立后台进程管理主机与默认开启的临时 HTTPS 隧道，Electron 提供渐入首页、扫码配对及连接控制。关闭电脑界面后服务继续运行。Android 原生 Activity 提供扫码连接与 API 模型获取/选择；前台服务管理手机本地运行，并提供加密凭据、文件保存和经过校验安装的 ARM64 Linux 用户态，App 内共用项目与会话界面。本地运行包含 Node、Git 和固定版本 Codex；PRoot 提供兼容环境，系统隔离由 Android App 提供。手机本地运行尚需设备验收。

电脑与常驻主机模式通过连接服务调用 Codex App Server；手机本地模式也优先探索同一协议。先验证公开接口能否满足需求，再决定是否需要维护 Codex CLI 的修改版本。
