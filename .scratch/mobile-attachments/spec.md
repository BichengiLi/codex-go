# 手机附件与内置本地会话

## Problem Statement
发送栏只能输入文字。连接电脑后需要返回首页才能打开手机本地会话，运行位置不够直观。

## Solution
发送栏支持文件、图片和音频附件；附件上传到当前会话的运行主机，在那里由模型与工具处理。Android 聊天界面内提供电脑会话与手机本地会话入口，保留电脑配对，手机本地继续复用已保存的模型 API。

## User Stories
1. 用户可从系统文件选择器选择多个附件，查看上传结果并移除待发送附件。
2. 手机本地会话可处理手机上传的文件；电脑会话可处理上传到电脑项目的文件。
3. 图片作为本地图片输入模型；其他文件提供主机文件路径，音频由运行主机可用工具处理。
4. 仅有附件也可发送；上传失败不会发送任务，发送结果未知时不自动重发。
5. 连接电脑后可直接打开手机本地会话，使用同一份手机 API 配置，再返回已配对电脑的会话。

## Implementation Decisions
- 两种运行主机共用鉴权上传 API；原生层通过系统文档选择器流式上传，Key 和文件字节不经过 JavaScript 桥。
- 上传保存在项目内专用目录，每个文件使用独立目录，不覆盖现有文件；限制大小、文件名、私有路径和越界链接。
- 附件引用在发送任务时重新校验归属；图片使用固定 App Server 的 localImage 输入。
- 电脑与手机会话独立，选择入口不迁移项目或会话，也不撤销配对。

## Testing Decisions
复用鉴权 HTTP 与 RPC fixture 验证二进制往返、越界与私有路径、附件任务输入和重复提交。构建共享界面及原生客户端，运行 Android 单元测试和 lint；设备行为仅在有设备时报告为实测。

## Out of Scope
跨主机自动迁移、录音、离线推理、替电脑修改模型 API 配置。
