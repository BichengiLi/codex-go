# 01: 在运行主机上传和处理消息附件

**What to build:** 手机和网页发送文件、图片、音频到当前会话运行主机，并在模型任务中引用。

**Blocked by:** None (can start immediately).

**Status:** complete (Android 设备验收另行记录)

- [x] 鉴权、路径保护、大小限制、二进制保存与下载往返。
- [x] 发送栏选择、显示、移除附件，支持仅附件消息和失败恢复。
- [x] Android 系统选择器直接流式上传，共用主机 API。
- [x] 图片进入模型视觉输入，其他附件提供可处理的文件路径。
