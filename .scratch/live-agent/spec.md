# 连接状态与实时任务进展

## Problem Statement
已配对原生 App 在检查连接时闪现八位码表单；任务执行期间思考摘要被隐藏，计划与工具生命周期依赖历史刷新，旧 HTTP 快照可能覆盖新输出。

## Solution
原生 App 使用连接中、重试或返回首页重新配对，浏览器仅在未配对时显示八位码。实时显示服务提供的思考摘要、计划、工具状态/输出和回复；等待期间显示明确执行状态，滚动只在用户位于底部时跟随。

## Implementation Decisions
- 两端共用通知投影；只展示模型服务公开提供的摘要，不构造思考内容。
- HTTP 历史携带事件序号和进程标识，客户端重放快照后的事件，避免覆盖流式内容。
- HTTPS 仍用隧道兼容的事件轮询，有输出时加快轮询；本地和 LAN 使用 SSE。
- 保留鉴权、事件缺口恢复及提交去重。原生 App 已持有配对凭据，无需再次输入八位码。

## Testing Decisions
使用现有 fixture/HTTP 测试和隔离窄屏界面验证连接检查、原生凭据失效、SSE/轮询的摘要/计划/工具/回复在任务结束前可见，以及延迟快照不回滚文字。

## Out of Scope
未公开的模型内部推理、服务不返回摘要时伪造内容、替换模型服务协议。
