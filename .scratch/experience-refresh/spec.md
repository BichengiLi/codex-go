# 双端体验与持久连接

## Problem Statement
电脑与手机首页暴露过多配置步骤，缺少扫码入口；电脑窗口退出会结束主机，设备凭据七天后失效。

## Solution
电脑打开即启动外网连接，中央标题与标语依次渐入，下滑后显示配对二维码。手机首页渐入品牌与“连接电脑 / 本地调用”两个入口。扫码完成配对；本地模式首次配置地址和 Key，获取并选择模型，后续直接进入聊天起始页。

## User Stories
1. 电脑用户打开应用即可准备外网配对。
2. 手机用户扫码即可连接，关闭任一界面后仍保留配对和电脑服务。
3. 用户可以主动停止电脑服务或撤销指定设备。
4. 本地用户可以获取服务模型列表、多选保存，并选择当前运行模型。
5. 已配置的本地用户无需再次填写 Key 即可开始聊天。

## Implementation Decisions
- 电脑后台进程持有主机和隧道，窗口仅通过带随机凭据的本机控制通道管理；再次打开复用已有进程。
- 电脑配对凭据持续有效，直到撤销；二维码仍为五分钟、单次使用，过期自动刷新。CLI 默认七天策略保持。
- 手机使用原生摄像头扫码、Keystore 保存凭据；返回首页和关闭界面不撤销配对。
- 模型列表通过用户 HTTPS 服务的 GET /models 获取，拒绝重定向，不向网页或日志传 Key；兼容性仍要求 Responses。
- 外网依赖网络和 Cloudflare Quick Tunnel，休眠期间不可达；电脑重启或隧道地址重建后需要重新扫码。

## Testing Decisions
复用主机协议测试，补充持久凭据、后台控制鉴权与窗口进程退出后的服务存活测试；双端构建、Android lint、桌面渲染与窄屏聊天检查。无 Android 设备时明确保留相机与后台真机验收。

## Out of Scope
iOS、Chat Completions 转换、电脑关机期间服务、跨主机迁移。
